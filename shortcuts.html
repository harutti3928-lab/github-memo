Windowsの一般ショートカット

ショートカット操作
Ctrl + Cコピー
Ctrl + X切り取り
Ctrl + V貼り付け
Ctrl + Z元に戻す（アンドゥ）
Ctrl + Yやり直す（リドゥ）
Ctrl + S保存
Ctrl + A全選択
Ctrl + Fページ内検索
Alt + Tabウィンドウの切り替え
Win + Dデスクトップを表示

Cursor（エディタ）のショートカット

ショートカット操作
Ctrl + Pファイルをすばやく開く
Ctrl + Shift + Pコマンドパレットを開く（何でもできる検索窓）
Ctrl + `ターミナルを開く・閉じる
Ctrl + /選択行をコメントアウト・解除
Ctrl + D同じ単語を次々選択（複数同時編集に便利）
Alt + ↑ / ↓行を上下に移動
Shift + Alt + ↓行をコピーして下に複製
Ctrl + Bサイドバーを表示・非表示
Ctrl + Shift + Eエクスプローラー（ファイル一覧）タブを開く
Ctrl + Shift + Gソース管理（Git）タブを開く
Ctrl + Z元に戻す
Ctrl + K, Ctrl + Oフォルダを開く（K を押してから O）

GitHubサイト上のショートカット

GitHubのページを開いた状態でキーボードだけで操作できる。

ショートカット操作
?そのページで使えるショートカット一覧を表示
Tリポジトリ内のファイルを検索
Lコードの行番号にジャンプ
Bファイルの変更履歴（blame）を表示
G + CCodeタブに移動
G + IIssuesタブに移動
G + PPull requestsタブに移動
S または /検索バーにフォーカス
