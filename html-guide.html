HTMLの書き方まとめ

← トップに戻る

HTMLとは

Webページの「構造と内容」を書くための言語。文章の見出し・段落・リンクなどを、タグと呼ばれる記号で表現する。

基本的な構造

HTMLファイルは必ずこの形から始まる。

<!DOCTYPE html>
<html lang="ja">
  <head>
    <meta charset="UTF-8">
    <title>ページのタイトル</title>
  </head>
  <body>
    ここに内容を書く
  </body>
</html>
  • <!DOCTYPE html>：「これはHTMLファイルです」という宣言
  • <html lang="ja">：ページ全体を囲むタグ。lang="ja"は日本語であることを示す。英語なら"en"になる
  • <head>：ブラウザへの設定情報を書く場所（画面には表示されない）
  • <meta charset="UTF-8">：文字コードをUTF-8にする。これを書かないと日本語が文字化けする。
  • <title>：タブの名前（タブに表示する文）であって、ブラウザ内に表示されるわけではない。
  • <body>：実際にブラウザに表示される内容を書く場所

タグの書き方

タグは「開始タグ」と「終了タグ」でコンテンツを挟む形が基本。

<p>ここが内容</p>

終了タグはスラッシュ（/）がつく。

よく使うタグ一覧

見出し

h1〜h6まであり、数字が大きいほど小さい見出しになる。

<h1>大見出し</h1>
<h2>中見出し</h2>
<h3>小見出し</h3>

段落

<p>ここに文章を書く。</p>

リンク

href属性（= リンク先のURL）を指定する。

<a href="https://github.com">GitHubへ</a>
GitHubへ

同じサイト内の別ページに飛ぶ場合はファイル名だけでよい。

<a href="index.html">トップに戻る</a>
トップに戻る

フォルダを跨いだリンクは、フォルダ名からファイル名までを指定する。

<a href="./html_css/index.html">トップに戻る</a>
トップに戻る

target属性を使うと、リンクを新しいタブで開くことができる。

<a href="index.html" target="_blank">新しいタブで開く</a>
新しいタブで開く

rel属性を使うと、リンクの種類を指定できる。noopener noreferrerは、リンクを開いたときにセキュリティを強化するためのもの。

<a href="index.html" rel="noopener noreferrer">トップに戻る</a>
トップに戻る

箇条書きリスト（順序なし）

<ul>
  <li>項目1</li>
  <li>項目2</li>
</ul>
  • 項目1
  • 項目2

番号つきリスト（順序あり）

<ol>
  <li>手順1</li>
  <li>手順2</li>
</ol>
  1. 手順1
  2. 手順2

太字・強調

<b>太字にしたい文字</b>

コードの表示

コードを表示するときは pre と code を組み合わせて使う。preはスペースや改行をそのまま表示し、codeはコンピュータ用の文字であることを示す。

<pre><code>git commit -m "メッセージ"</code></pre>
git commit -m "メッセージ"

特殊文字（& から始まる書き方）

HTMLでは < や > などの記号は 特別な意味を持つため、そのまま書くとタグだと解釈されてしまう。 これらを「文字として」表示したいときは、 & で始まり ; で終わる 「文字参照」という書き方を使う。

書き方 表示される文字 意味
&lt; < 小なり（タグの開始記号）
&gt; > 大なり（タグの終了記号）
&amp; & アンド記号
&quot; " ダブルクォート

画像

src属性に画像ファイルのパス、alt属性に画像が表示できないときの代替テキストを書く。終了タグは不要。

<img src="image.png" alt="画像の説明">

属性とは

タグに追加情報を渡すためのもの。開始タグの中に 属性名="値" の形で書く。

<a href="index.html" target="_blank">新しいタブで開く</a>

上の例では href と target が属性。target="_blank" は「新しいタブで開く」という意味。
