リポジトリページの各タブ

GitHubのリポジトリページで確認できる主な情報。

  1. Code タブ：ファイル一覧と最新のコードが見える
  2. Issues タブ：バグ報告や改善要望を管理する場所、TO DOリストとかもここに作る
  3. Pull requests タブ：変更をレビューしてもらい本体に取り込む仕組み
  4. Actions タブ：自動テストや自動デプロイの実行履歴
  5. Settings タブ：リポジトリの設定（GitHub Pagesの設定もここ）
  6. コミット履歴：Codeタブの時計アイコンから、誰がいつ何を変えたか確認できる

READMEとは

リポジトリの「説明書」として、Codeページを開いたときにファイル一覧の下に自動で表示されるファイル。 ファイル名は README.md（大文字）で、リポジトリのトップに置く。

プロジェクトの概要・使い方・作者情報などを書くのが一般的。 GitHubでリポジトリを作ると「Add a README」ボタンが表示されるのはこれを作るため。

READMEの追加方法

  1. GitHubのリポジトリページで「Add a README」ボタンを押す
  2. 内容を入力して、ページ右上の「Commit changes」ボタンを押す
  3. Codeページに戻ると、ファイル一覧の下にREADMEの内容が表示される

ローカル（自分のPC）に README.md を作って push する方法でも同じ結果になる。

リポジトリをクローン（ダウンロード）する

クローンとは、GitHubにあるリポジトリを自分のPCにコピーしてくること。

SSHのURLを使ったクローン手順

  1. GitHubのリポジトリページで緑色の「Code」ボタンを押す
  2. 「Local」タブの中の「SSH」を選ぶ
  3. 表示されたURL（git@github.com:ユーザー名/リポジトリ名.git）をコピーする
  4. ターミナルで以下のコマンドを実行する 
    git clone git@github.com:ユーザー名/リポジトリ名.git

SSHを使うには事前にSSHキーの設定が必要。設定方法はGitHubの基本ページを参照。
