Cursorでフォルダを開いてから、GitHub Pagesでサイトを公開するまでの手順。

  1. Cursorで新しくフォルダを開く(Ctrl+M, Ctrl+O)

    メニューの「File → Open Folder」から、作業用のフォルダを開く。

  2. ソース管理タブから「リポジトリを初期化」を押す（git init）

    左側のアイコンからソース管理タブを開き、「リポジトリを初期化」ボタンを押す。

    するとフォルダ内に.gitという名前の隠しフォルダが作成され、その中で履歴等が管理されることになる。

    リポジトリとは、.gitが存在するフォルダのこと。

  3. ファイルをステージする（git add ファイル名）

    ソース管理タブに変更されたファイルが表示される。 ファイル名の横にある「＋」ボタンを押すと、そのファイルがステージされる（次のコミットに含める対象として選ばれる）。 これは、git add ファイル名というコマンドと同じ。

  4. コミットする（git commit -m "コミットメッセージ"）

    ステージしたファイルに対して、変更内容のメモ（コミットメッセージ）を入力して「コミット」ボタンを押す。これで変更が記録される。 これは、git commit -m "コミットメッセージ"というコマンドと同じ。

  5. 「ブランチの発行」を押す（git push）

    コミット後、ソース管理タブに「ブランチの発行」ボタンが表示される。 これを押すとGitHubにリポジトリが自動で作られ、コミットした内容がアップロードされる。 これは、git pushというコマンドと同じ。

    この際、privateかpublicを選ぶことができる。privateを選ぶと、リポジトリは自分だけが見れる状態になる。 publicを選ぶと、リポジトリは誰でも見れる状態になる。 公開したい場合はpublicを選ぶ。

  6. GitHubのSettings → Pagesを開く

    GitHubのリポジトリページを開き、上部の「Settings」タブをクリック。左側のメニューから「Pages」を選ぶ。

    「Branch」の項目で「main」を選び、フォルダは「/ (root)」のままにして「Save」ボタンを押す。

    暫く経つと、URLが表示されるので、サイトが公開されていることを確認する。

Terminalを使ってfirst pushする方法

GUIのボタンではなく、ターミナルにコマンドを打って公開する方法。 やっていることは上のGUIの手順と同じで、対応するコマンドを自分で打つ点だけが違う。

  1. リポジトリを初期化する

    git init

    フォルダ内に.gitが作られ、Git管理が始まる。GUIの「リポジトリを初期化」と同じ。

  2. ファイルをステージする

    git add index.html

    コミットに含めるファイルを選ぶ。すべての変更をまとめてステージしたいときは git add .（ドット）と書くと、フォルダ内の全ファイルが対象になる。

  3. コミットする

    git commit -m "1st commit"

    ステージした内容を、メッセージ付きで記録する。

  4. GitHubに空のリポジトリを作る

    ブラウザでGitHubを開き、「New repository」から同名のリポジトリを作る。 このときREADMEなどの初期ファイルは追加しない（空のまま作る）。 手元にすでにコミットがあるので、両方にファイルがあるとぶつかってしまうため。

  5. リモート（送り先）を紐付ける

    git remote add origin https://github.com/ユーザー名/リポジトリ名.git

    手元のリポジトリ（ローカル）と、GitHub上のリポジトリ（リモート）をつなぐ。 originは送り先につけるあだ名。リポジトリ作成後にGitHubが表示してくれるコマンドをコピーすればよい。

  6. ブランチ名をmainにする

    git branch -M main

    初期のブランチ名がmasterになっている場合があるので、GitHubの標準であるmainに変更する。

  7. プッシュする

    git push -u origin main

    originのmainに向けて送信する。-uを付けると次回以降はgit pushだけで送れるようになる。
