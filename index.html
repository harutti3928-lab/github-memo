GitHubの使い方メモ

GitHubとは何か

コードやファイルをインターネット上で管理・共有できるサービス。

  1. ファイルの変更履歴を記録できる（いつ・何を変えたか残る）
  2. 過去の状態に戻せる
  3. 他の人と共同作業ができる
  4. 作ったものを無料で公開できる（GitHub Pages）

最初の設定

GitHubを使い始める前に一度だけやる設定。

  1. GitHub（github.com）でアカウントを作る
  2. 自分のPCにGitをインストールする
    Windowsの場合：git-scm.com からインストーラーをダウンロードして実行する（よくある、このアプリがPCに変更を与えてもよろしいですか、の奴）
  3. ターミナルで名前とメールアドレスを登録する 
    
          git config --global user.name "あなたの名前"
          git config --global user.email "あなたのメールアドレス"
          （この2つは、GitHubの設定と同じである必要がある）
  4. SSHキーを作ってGitHubに登録する（パスワード不要で接続できるようになる） 
    
          ssh-keygen -t ed25519 -C "あなたのメールアドレス"
    生成された公開キーをGitHubの Settings → SSH keys に貼り付ける

よく使う操作

日常的に使うGitのコマンド一覧。

  1. リポジトリをクローンする（ダウンロードしてくる） 
    git clone リポジトリのURL
  2. 変更したファイルを記録対象に追加する 
    git add ファイル名
  3. 変更内容を確定（コミット）する 
    git commit -m "変更内容のメモ"
  4. GitHubに送信（プッシュ）する 
    git push
  5. GitHubから最新の状態を取得（プル）する 
    git pull

各種操作の意味

Gitの用語と操作が何を意味しているかの整理。

  1. リポジトリ：ファイルと変更履歴をまとめた保管場所
  2. クローン：GitHubにあるリポジトリを自分のPCにコピーすること
  3. add：「次のコミットにこのファイルを含める」と指定すること
  4. コミット：変更内容にメモをつけて確定・記録すること
  5. プッシュ：自分のPCの記録をGitHubに送ること
  6. プル：GitHubの最新状態を自分のPCに取り込むこと
  7. ブランチ：本体に影響を与えずに作業できる分岐した作業スペース

GitHubの見方

GitHubのリポジトリページで確認できる主な情報。

  1. Code タブ：ファイル一覧と最新のコードが見える
  2. Issues タブ：バグ報告や改善要望を管理する場所
  3. Pull requests タブ：変更をレビューしてもらい本体に取り込む仕組み
  4. Actions タブ：自動テストや自動デプロイの実行履歴
  5. Settings タブ：リポジトリの設定（GitHub Pagesの設定もここ）
  6. コミット履歴：Codeタブの時計アイコンから、誰がいつ何を変えたか確認できる
